# 🎓 Student Tech Hub

A beginner-friendly full-stack web application for discovering upcoming technical events and registering as a student.

## 🚀 Features

- 📅 View upcoming technical events
- 👨‍🏫 Event speaker and description information
- 📝 Student registration
- 🔗 Frontend connected to a FastAPI backend
- 📡 REST API endpoints
- 📱 Responsive web interface
- 🧩 Simple and easy-to-understand architecture

## 🛠️ Tech Stack

### Frontend
- HTML5
- CSS3
- JavaScript

### Backend
- Python
- FastAPI
- Uvicorn

### Development Tools
- Git
- GitHub
- VS Code / Antigravity
